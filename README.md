# Venture Cafe NFC Workshop
You brought a phone. You're about to leave with a sidekick. Programme an NFC sticker to fire off a link, a contact card, or a full Tasker routine, one tap at a time. Instructions and an idea database live here.

## 🌐 Site

This repo is a static site (`index.html` + `assets/`) meant to be served with **GitHub Pages**:

1. Go to **Settings → Pages** on this repository.
2. Under **Build and deployment**, set **Source** to `Deploy from a branch`.
3. Pick the branch this site lives on and `/ (root)` as the folder, then **Save**.
4. GitHub publishes it at `https://<owner>.github.io/<repo>/` within a minute or two.

No build step, no dependencies — just static HTML/CSS/JS.

### What's on the page

- A short primer on NFC + Tasker, with a collapsible deep-dive on how tag reads and Tasker's NFC bridge actually work.
- Step-by-step instructions for programming a tag, each step labelled 🟢 Beginner / 🟡 Intermediate / 🔴 Advanced.
- A filterable, gamified **idea bank** (serious/practical vs. silly/whimsical) — expanding a card earns XP toward a rank, tracked locally in your browser.
- A Tasker-specific setup guide and a second Tasker-only idea bank, for routines that go beyond what a plain tag can do.
