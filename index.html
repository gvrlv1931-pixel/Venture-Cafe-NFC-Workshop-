01 What Is NFC + Tasker?

NFC (Near Field Communication) is a short-range radio standard built into most modern smartphones. An NFC tag is a small, battery-free sticker containing a chip and antenna that can store a limited amount of data. Tapping a phone against a tag reads that data immediately: a web link, a contact card, a Wi-Fi network, or a trigger for an automation.

Tasker is an Android automation app that runs sequences of actions, such as adjusting settings, opening apps, and sending messages. Paired with an NFC tag, a single tap can trigger one of these sequences.

Read more: how NFC and Tasker work

The physics

NFC tags are passive: they contain no battery. A phone's NFC antenna, usually located on the upper back near the camera, generates a small electromagnetic field at 13.56 MHz. When a tag enters that field, the field powers the chip briefly, long enough to transmit its stored data to the phone. Range is limited to a few centimetres by design, which prevents accidental reads.

What is stored

Tag data is written using a standard format called NDEF (NFC Data Exchange Format), organised into records: a URI record, a Text record, a Contact (vCard) record, a Wi-Fi credentials record, and others. A tag can hold multiple records, read in sequence. Common sticker chips include:

  • NTAG213: approximately 144 bytes total, around 137 bytes usable for NDEF data. Enough for one URL or a short line of text.
  • NTAG215: approximately 504 bytes total, around 492 bytes usable. Room for a full contact card or a couple of combined records.
  • NTAG216: approximately 888 bytes total, around 868 bytes usable. Suitable for multiple records or longer text.

Reading a tag: Android and iPhone

On Android, tapping a tag with the screen on and NFC enabled is normally enough. The system reads the tag and opens the appropriate app automatically for basic record types, without requiring an app to be open first. On iPhone, background tag reading works without opening an app on iPhone XS and later. Earlier models, iPhone 7 through X, require the Control Centre NFC shortcut or an app to start the scan.

Where Tasker fits in

Tasker is Android only. Android limits which apps are allowed to register as the system handler for a generic tag-read event, and Tasker is not one of them by default. To connect a tag read to a Tasker profile, a small bridge app such as NFC for Tasker is required. Setup instructions are provided in the Tasker section below.

02 Program an NFC Tag

Programming a tag requires two things: a blank NFC tag and a writer app. The steps below cover the process from blank sticker to working tag.

  1. 1Get a blank tagLEVEL 1: BASIC

    NTAG213 stickers are the most common and least expensive option, suitable for links, contact cards, and Wi-Fi credentials. NTAG215 or NTAG216 suit multiple records or longer content, such as a full contact card. Blank tags are typically sold in packs of 10 to 25.

  2. 2Install a writer appLEVEL 1: BASIC

    NFC Tools (Android and iOS) is a widely used option for reading, writing, cloning, and locking tags. It is free to install, with optional paid features. This guide refers to it throughout, though other writer apps work in a similar way.

  3. 3Choose a record typeLEVEL 1: BASIC

    In NFC Tools, go to Write, then Add a record. Suitable starting record types are URL, Text, Contact, and Wi-Fi network. Fill in the details and confirm.

  4. 4Add more advanced content (optional)LEVEL 2: INTERMEDIATE

    An App launch record opens a specific app directly on Android. This record type is not supported on iPhone; iOS users would need a separate Shortcuts automation to achieve something similar. Multiple records can also be combined on a single tag; the phone will show a selection menu when the tag is read.

  5. 5Write the tagLEVEL 1: BASIC

    Select Write, then hold the back of the phone against the tag for one to two seconds until the app confirms success. Antenna position varies by phone model; if nothing happens, move the tag slowly across the back of the phone.

  6. 6Test the tagLEVEL 1: BASIC

    Lock the phone, then tap the tag again to confirm it behaves as expected under normal conditions, since writing and reading can use slightly different phone positioning.

  7. 7Lock the tag (optional, not reversible)LEVEL 3: ADVANCED

    NFC Tools includes a Lock tag option that permanently write-protects the tag. This is useful for tags that will be distributed publicly. It cannot be undone, so confirm the content is correct before locking.

NOTE Label programmed tags physically, for example with a small sticker or marker, once more than one is in use. A blank tag and a programmed tag look identical from the outside.

04 Tasker Automation

Tasker (Android only) uses profiles made of a trigger, called a context, and an action, called a task. Paired with NFC, a tag read can act as the trigger for a task containing several actions.

Read more: connecting NFC tags to Tasker

As described above, Tasker cannot register itself as the handler for a generic tag-read event. Two approaches bridge this:

  • NFC for Tasker (plugin app): provides an Event, Plugin, NFC for Tasker trigger inside Tasker. It can be configured to fire on any tag, or scanned once to filter to a specific tag. This is the more flexible option for profiles with conditions, variables, or multi-step tasks.
  • NFC Tools' Task record with NFC Tasks (companion app): writes a tag that names one specific Tasker task directly. Tapping the tag runs that task without any profile setup inside Tasker. Faster to set up for a single tag, less flexible for branching logic.

Either approach requires Tasker's external access setting to be enabled, found in Tasker's preferences under the option that allows plugins or third-party apps to run tasks. The phone's NFC radio and screen also need to be on to read or write a tag.

One tag, two behaviours: to make a single tag behave differently depending on state, for example silencing the phone on the way out and restoring it on the way back in, store a value in a Tasker variable and add a condition in the task that checks and updates it.

Setting It Up

  1. 1Install Tasker and NFC for TaskerLEVEL 1: BASIC

    Both are available on the Play Store. Tasker is a paid app with a one-time cost; NFC for Tasker is a separate plugin.

  2. 2Enable external accessLEVEL 1: BASIC

    In Tasker, open Preferences, then Misc, and enable the option that allows external apps or plugins to run tasks.

  3. 3Create the profileLEVEL 1: BASIC

    Select New Profile, then Event, Plugin, NFC for Tasker. Open its settings and either scan a specific tag to filter to it, or leave it unfiltered to respond to any tag.

  4. 4Build the taskLEVEL 2: INTERMEDIATE

    Attach a new task and add actions in order, for example toggling Wi-Fi, adjusting volume, launching an app, or sending an HTTP request.

  5. 5Test with the screen onLEVEL 1: BASIC

    Tap the tag with the phone unlocked to confirm the profile runs as expected. Check Tasker's run log if it does not.

  6. 6Add conditional logicLEVEL 3: ADVANCED

    Introduce a Tasker variable to store state, and an If action to branch the task, turning a single tag into a two-way or multi-way switch.
