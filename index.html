01 What Is NFC + Tasker?

NFC (Near Field Communication) is a short-range radio standard built into almost every modern smartphone. A cheap, battery-free NFC tag — a coin-sized sticker with a tiny chip and antenna — can store a small piece of data. Tap your phone against it, and your phone reads that data instantly: a web link, a contact card, a Wi-Fi password, or a trigger for a whole automation.

Tasker is an Android automation app that goes far beyond "open this link." Pair it with an NFC tag and a single tap can silence your phone, launch three apps, send a message, and set a timer — all at once, all offline.

▸ Read more: how NFC and Tasker actually work under the hood

The physics (short version)

NFC tags are passive — they have no battery. Your phone's NFC antenna (usually on the upper back, near the camera) emits a small electromagnetic field at 13.56 MHz. When a tag enters that field, the field itself powers the chip just long enough to transmit its stored data back to the phone. Range is tiny by design — a few centimetres — which is what makes it deliberate and secure: you can't "tap" something by accident from across a room.

What's actually stored

Data is written in a standard format called NDEF (NFC Data Exchange Format), organised into records — a URI record, a Text record, a Contact (vCard) record, a Wi-Fi credentials record, and so on. A tag can hold multiple records, read in order. Cheap "sticker" chips come in a few common sizes:

  • NTAG213 — ~144 bytes usable (~137 for NDEF). Plenty for one URL or a short text.
  • NTAG215 — ~504 bytes (~492 usable). Room for a vCard or a couple of records.
  • NTAG216 — ~888 bytes (~868 usable). Multiple records, longer text, Smart Posters.

Reading a tag: Android vs iPhone

On Android, just tap — with the screen on and NFC enabled, the system reads the tag and hands the data to the right app automatically (no app needs to be open first for basic records). On iPhone, background tag reading works out of the box on iPhone XS and later; older models (7 through X) need the Control Centre NFC shortcut or an app to start the scan. Either way, no special app is required just to read a simple link or text tag.

Where Tasker fits in

Tasker is Android-only. Here's the part most tutorials skip: Tasker cannot register itself as the system's NFC tag handler — only a small set of apps are allowed to catch that "a tag was just read" event. So Tasker relies on a lightweight bridge app (like NFC for Tasker) that is allowed to catch it, and hands the event over to a Tasker profile. It's one extra app to install, not a limitation of the sticker itself. Full setup is in the Tasker section below.

02 Programme an NFC Tag

You need two things: a blank NFC tag, and a free writer app. That's it. Here's the full path from blank sticker to working tag.

  1. 1Get a blank tag🟢 BEGINNER

    Buy a pack of NTAG213 stickers for basics (links, contact cards, Wi-Fi) — they're the cheapest and most common. Go for NTAG215/216 if you plan to pack in multiple records or a full vCard. Sold in bulk for roughly the price of a coffee for a pack of 10–25.

  2. 2Install a writer app🟢 BEGINNER

    NFC Tools (free, Android & iOS) is the standard all-rounder — reads, writes, clones, and locks tags, with a clean record builder. It's the app referenced throughout this page.

  3. 3Choose a record type🟢 BEGINNER

    In NFC Tools, go to Write > Add a record. Beginner-friendly types: URL/URI, Text, Contact. Fill it in and tap OK.

  4. 4Level up the record (optional)🟡 INTERMEDIATE

    Try a Wi-Fi network record (auto-joins guests), an App launch record (opens a specific app), or stack multiple records on one tag (phone shows a chooser on tap).

  5. 5Write it🟢 BEGINNER

    Tap Write, then hold the back/upper-back of your phone against the tag for 1–2 seconds until you get a success buzz or confirmation. Tag layout varies by phone — if nothing happens, slowly slide the tag around the back of the phone.

  6. 6Test it🟢 BEGINNER

    Lock your phone and tap the tag again, for real — writing and reading use slightly different phone positioning, and it's the only way to know it'll work for someone else's phone too.

  7. 7Lock the tag (optional, irreversible)🔴 ADVANCED

    NFC Tools' Lock tag option permanently write-protects it — nobody (including you) can overwrite it after. Good for tags you're handing out publicly; skip it while you're still experimenting.

💡 Tip: label your tags physically (a small sticker or marker note) once you've got a few going — from the outside, a blank tag and a programmed one look identical.

04 Level Up With Tasker

Tasker (Android only) turns your phone into a programmable machine: profiles made of a trigger (context) and an action (task). Paired with NFC, a single tap can run an entire routine instead of just opening a link.

▸ Read more: how NFC and Tasker connect

As covered above, Tasker can't catch the system's raw "tag was read" event by itself — Android restricts that to a small set of apps. Two reliable bridges:

  • NFC for Tasker (free plugin) — gives Tasker a proper Event → Plugin → NFC for Tasker trigger. Configure it to fire on any tag, or scan a specific tag once to filter to just that one. This is the right choice for building real profiles with conditions, variables, and multi-step tasks.
  • NFC Tools' "Task" record + NFC Tasks (free companion app) — write a tag that names one specific Tasker task directly; tapping it runs that task with zero profile setup on the Tasker side. Faster for a single one-off tag, less flexible for branching logic.

Either route needs Tasker's external access / "allow all apps" permission switched on (in Tasker's own preferences) so the bridge app is allowed to launch tasks. Also: both the phone's NFC radio and screen must be on to read or write a tag — Tasker can't wake NFC from a fully asleep phone.

One tag, two behaviours: want the same tag to silence your phone on the way out and restore it on the way back in? Store a toggle in a Tasker variable (e.g. %HomeState) and add an If condition in the task that checks and flips it. One sticker, two outcomes, depending on state.

Setting It Up

  1. 1Install Tasker + NFC for Tasker🟢 BEGINNER

    Both from the Play Store. Tasker has a small one-time cost or trial; NFC for Tasker is free.

  2. 2Enable external access🟢 BEGINNER

    In Tasker: Menu → Preferences → Misc → Allow External Access. Without this, plugins can't fire tasks.

  3. 3Create the profile🟢 BEGINNER

    New Profile → Event → Plugin → NFC for Tasker. Tap the edit (pencil) icon, then Scan tag to filter to one specific tag, or leave it open to catch any tag.

  4. 4Build the task🟡 INTERMEDIATE

    Attach a new Task and stack actions — Wi-Fi toggle, volume/DND, launch app, send message, HTTP request, whatever the routine needs. Order matters; drag to reorder.

  5. 5Test with screen on🟢 BEGINNER

    Tap the tag with the screen unlocked to confirm the profile fires. Check Tasker's run log if it doesn't.

  6. 6Add toggle logic🔴 ADVANCED

    Introduce a Tasker variable to track state, and an If action to branch the task — turning one static tag into a two-way (or multi-way) switch.
