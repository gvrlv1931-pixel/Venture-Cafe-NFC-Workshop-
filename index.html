01 What Is NFC + Tasker?

NFC (Near Field Communication) is a short-range radio standard built into most modern smartphones. An NFC tag is a small, battery-free sticker containing a chip and antenna that can store a limited amount of data. Tapping a phone against a tag reads that data immediately: a web link, a contact card, a Wi-Fi network, or a trigger for an automation.

Tasker is an Android automation app that runs sequences of actions, such as adjusting settings, opening apps, and sending messages. Paired with an NFC tag, a single tap can trigger one of these sequences.

Read more: how NFC and Tasker work

The physics

NFC tags are passive: they contain no battery. A phone's NFC antenna, usually located on the upper back near the camera, generates a small electromagnetic field at 13.56 MHz. When a tag enters that field, the field powers the chip briefly, long enough to transmit its stored data to the phone. Range is limited to a few centimetres by design, which prevents accidental reads.

What is stored

Tag data is written using a standard format called NDEF (NFC Data Exchange Format), organised into records: a URI record, a Text record, a Contact (vCard) record, a Wi-Fi credentials record, and others. A tag can hold multiple records, read in sequence. Common sticker chips include:

  • NTAG213: approximately 144 bytes total, around 137 bytes usable for NDEF data. Enough for one URL or a short line of text.
  • NTAG215: approximately 504 bytes total, around 492 bytes usable. Room for a full contact card or a couple of combined records.
  • NTAG216: approximately 888 bytes total, around 868 bytes usable. Suitable for multiple records or longer text.

Reading a tag: Android and iPhone

On Android, tapping a tag with the screen on and NFC enabled is normally enough. The system reads the tag and opens the appropriate app automatically for basic record types, without requiring an app to be open first. On iPhone, background tag reading works without opening an app on iPhone XS and later. Earlier models, iPhone 7 through X, require the Control Centre NFC shortcut or an app to start the scan.

Where Tasker fits in

Tasker is Android only. Android limits which apps are allowed to register as the system handler for a generic tag-read event, and Tasker is not one of them by default. To connect a tag read to a Tasker profile, a small bridge app such as NFC for Tasker is required. Setup instructions are provided in the Tasker section below.

02 Program an NFC Tag

Programming a tag requires two things: a blank NFC tag and a writer app. The steps below cover the process from blank sticker to working tag.

  1. 1Get an NFC tagLEVEL 1: BASIC

    If you are at the Venture Café workshop, tags are provided, so you can skip ahead to Step 2. If you are following this guide elsewhere, NTAG213 stickers are the most common and least expensive option, suitable for links, contact cards, and Wi-Fi credentials. NTAG215 or NTAG216 suit multiple records or longer content, such as a full contact card. Blank tags are typically sold in packs of 10 to 25.

  2. 2Install a writer appLEVEL 1: BASIC

    NFC Tools (Android and iOS) is a widely used option for reading, writing, cloning, and locking tags. It is free to install, with optional paid features. This guide refers to it throughout, though other writer apps work in a similar way.

  3. 3Choose a record typeLEVEL 1: BASIC

    In NFC Tools, go to Write, then Add a record. Suitable starting record types are URL, Text, Contact, and Wi-Fi network. Fill in the details and confirm.

  4. 4Add more advanced content (optional)LEVEL 2: INTERMEDIATE

    An App launch record opens a specific app directly on Android. This record type is not supported on iPhone; iOS users would need a separate Shortcuts automation to achieve something similar. Multiple records can also be combined on a single tag; the phone will show a selection menu when the tag is read.

  5. 5Write the tagLEVEL 1: BASIC

    Select Write, then hold the back of the phone against the tag for one to two seconds until the app confirms success. Antenna position varies by phone model; if nothing happens, move the tag slowly across the back of the phone.

  6. 6Test the tagLEVEL 1: BASIC

    Lock the phone, then tap the tag again to confirm it behaves as expected under normal conditions, since writing and reading can use slightly different phone positioning.

  7. 7Lock the tag (optional, not reversible)LEVEL 3: ADVANCED

    NFC Tools includes a Lock tag option that permanently write-protects the tag. This is useful for tags that will be distributed publicly. It cannot be undone, so confirm the content is correct before locking.

NOTE Label programmed tags physically, for example with a small sticker or marker, once more than one is in use. A blank tag and a programmed tag look identical from the outside.

03 Troubleshooting

NFC is short-range and physical, so most problems come down to the tag and the phone not being close enough, aligned enough, or clear enough of interference, not a broken tag. Work through the general list first, then check the section for your phone.

CHECK FIRST If nothing happens at all when you tap, confirm NFC is switched on in the phone's settings before anything else. It ships turned off on a lot of Android phones, and Airplane Mode silently disables it on every phone.

General, any phone

  • NFC has to be on. See the callout above. On Android this is a setting that can be off by default; on iPhone it is always on unless Airplane Mode is active.
  • Metal blocks and interferes with the signal. A metal phone case, a case with a metal kickstand or MagSafe ring, an RFID-blocking wallet, a stack of credit cards, or even the tag resting on a metal desk can weaken or fully block the field. Take the tag and phone away from metal and try again.
  • Stacked tags or cards confuse the reader. If the tag is inside a wallet or card holder next to other NFC/RFID cards, the phone may not be able to isolate a single signal. Pull the tag out on its own and test it separately.
  • The antenna isn't where you think it is. Its position on the back of the phone varies by model and isn't always centred. If nothing happens, slowly slide the tag across the whole back of the phone rather than holding it in one spot.
  • Hold it steady for a second or two. A read needs the tag to sit in the field briefly; tapping and pulling away too fast can interrupt it, especially through a case.
  • Check the distance. NFC only works within a few centimetres. A thick case, wallet, or pop-socket can add just enough distance to push the tag out of range.
  • A tag that used to work and now doesn't may have been locked (Step 7 in Program an NFC Tag, which is permanent), overwritten with something else, or physically damaged. Re-check it with the writer app's Read function.

iPhone

  • iPhone XS and later read tags in the background automatically, no app needs to be open, and there is no separate NFC toggle to hunt for. If it isn't working, the most likely causes are Airplane Mode, metal interference, or the tag being out of range or unsupported (see below).
  • iPhone 7, 8, and X cannot read tags in the background. Add the NFC Tag Reader control once, in Settings, then Control Centre, then Customise Controls, then open it from Control Centre each time and hold the tag near the top of the phone, close to the camera, not the middle of the back.
  • Unsupported record types are silently ignored. iOS does not support Android's App Launch record type, so a tag written with one will do nothing on iPhone. Use a URL or Text record instead, or build an equivalent using the Shortcuts app.
  • A tap on a locked screen queues the action but may not open it immediately. That's expected: unlock the phone to see the result, it isn't a failed read.

Android

  • Turn NFC on under Settings, then Connected devices, then Connection preferences, then NFC (wording and location vary by manufacturer, for example Samsung uses Settings, then Connections, then NFC and contactless payments). Many phones also let you add an NFC quick-settings tile for a faster on/off toggle.
  • Battery saver modes disable NFC on some phones. If reads stop working intermittently, check whether a power-saving mode is active.
  • A "Complete action using" chooser means more than one app can handle the tag. Pick the one you want, choosing "Always" to stop being asked, or "Just once" to keep being asked each time. For a Tasker tag, choose NFC for Tasker.
  • For Tasker specifically: if the profile never seems to fire, confirm Tasker's external access setting is on (Preferences, then Misc), which is required for any plugin, including NFC for Tasker, to run a task. See the Tasker section for the full setup.

05 Tasker Automation

Tasker (Android only) uses profiles made of a trigger, called a context, and an action, called a task. Paired with NFC, a tag read can act as the trigger for a task containing several actions.

Read more: connecting NFC tags to Tasker

As described above, Tasker cannot register itself as the handler for a generic tag-read event. Two approaches bridge this:

  • NFC for Tasker (plugin app): provides an Event, Plugin, NFC for Tasker trigger inside Tasker. It can be configured to fire on any tag, or scanned once to filter to a specific tag. This is the more flexible option for profiles with conditions, variables, or multi-step tasks.
  • NFC Tools' Task record with NFC Tasks (companion app): writes a tag that names one specific Tasker task directly. Tapping the tag runs that task without any profile setup inside Tasker. Faster to set up for a single tag, less flexible for branching logic.

Either approach requires Tasker's external access setting to be enabled, found in Tasker's preferences under the option that allows plugins or third-party apps to run tasks. The phone's NFC radio and screen also need to be on to read or write a tag.

One tag, two behaviours: to make a single tag behave differently depending on state, for example silencing the phone on the way out and restoring it on the way back in, store a value in a Tasker variable and add a condition in the task that checks and updates it.

If nothing happens when you tap the tag: Android sometimes shows a chooser asking which app should handle it, if more than one app on the phone could respond to a tag read. Select NFC for Tasker, and choose "Always" or "Just once" depending on whether other NFC apps are also in use. If no chooser appears and nothing happens either, confirm the profile is scanned to the correct tag and that the screen was on at the moment of the tap.

Setting It Up

  1. 1Install Tasker and NFC for TaskerLEVEL 1: BASIC

    Both are available on the Play Store. Tasker is a paid app with a one-time cost; NFC for Tasker is a separate plugin.

  2. 2Enable external accessLEVEL 1: BASIC

    In Tasker, open Preferences, then Misc, and enable the option that allows external apps or plugins to run tasks.

  3. 3Create the profileLEVEL 1: BASIC

    Select New Profile, then Event, Plugin, NFC for Tasker. Open its settings and either scan a specific tag to filter to it, or leave it unfiltered to respond to any tag.

  4. 4Build the taskLEVEL 2: INTERMEDIATE

    Attach a new task and add actions in order, for example toggling Wi-Fi, adjusting volume, launching an app, or sending an HTTP request.

  5. 5Test with the screen onLEVEL 1: BASIC

    Tap the tag with the phone unlocked to confirm the profile runs as expected. Check Tasker's run log if it does not.

  6. 6Add conditional logicLEVEL 3: ADVANCED

    Introduce a Tasker variable to store state, and an If action to branch the task, turning a single tag into a two-way or multi-way switch.

06 Worked Examples: Word of the Day

One idea, built three times at increasing difficulty: a tag that looks up the word of the day. The Basic version needs only a phone and a tag. The Intermediate version has Tasker read it aloud. The Advanced version moves on to a different tag entirely, one that decides where to navigate based on the time and day. Each one is written out click by click rather than as hints to reveal, since these are meant to be followed directly.

Basic: look up the word of the day (NFC only)

A single URL record. Tapping the tag opens today's word straight in the browser, no app setup beyond NFC Tools.

  1. 1Open NFC Tools and go to WriteLEVEL 1: BASIC

    Open the app, then tap the Write tab at the bottom of the screen.

  2. 2Add a URL recordLEVEL 1: BASIC

    Tap Add a record, then choose URL/URI from the list of record types.

  3. 3Enter the addressLEVEL 1: BASIC

    Type https://www.merriam-webster.com/word-of-the-day into the address field, then tap OK to add it to the write queue.

  4. 4Write the tagLEVEL 1: BASIC

    Tap Write at the bottom of the screen, then hold the back of the phone against the tag for one to two seconds until it confirms.

  5. 5Test itLEVEL 1: BASIC

    Lock the phone, then tap the tag again. It should open the browser directly on that day's word.

Intermediate: the same idea, read aloud by Tasker

Android and Tasker only. This one fetches the page in the background and speaks the word instead of showing it, so it needs a fresh, blank tag rather than the one from the Basic example above: a tag already carrying a URL record competes with Tasker for the "complete action using" chooser (see Troubleshooting), so keep this tag free of any NFC Tools records and let Tasker be the only thing that responds to it.

  1. 1Confirm the basics are in placeLEVEL 1: BASIC

    Tasker and NFC for Tasker are installed, and Tasker's external access is switched on (Preferences, then Misc). See Tasker Automation if this isn't done yet.

  2. 2Create the profileLEVEL 2: INTERMEDIATE

    Open Tasker, go to the Profiles tab, tap +, then Event, then Plugin, then NFC for Tasker. Tap the pencil/edit icon, then Scan Tag, and tap the blank tag against the phone to filter the profile to it.

  3. 3Attach a new taskLEVEL 2: INTERMEDIATE

    Tasker prompts for a task name. Type Word of the Day and tap the checkmark.

  4. 4Fetch the pageLEVEL 2: INTERMEDIATE

    Tap + to add an action, then Net, then HTTP Request. Set Method to GET and URL to https://www.merriam-webster.com/word-of-the-day, then tap the back arrow to save the action. Tasker stores the response text in its built-in %HTTPD variable automatically.

  5. 5Copy the result into your own variableLEVEL 2: INTERMEDIATE

    Add another action: Variables, then Variable Set. Set Name to %WOTD and To to %HTTPD, then save. Keeping a copy in a variable you named yourself makes the next step easier to re-run if you need to adjust it later.

  6. 6Trim it down to just the wordLEVEL 3: ADVANCED

    Add: Variables, then Variable Search Replace. Variable: %WOTD. Turn on Use Regex and Replace Matches. Search: Word of the Day: ([^<|]+). Replace With: %1. Save. This matches the word in the page's title text and replaces the whole variable with just the captured word.

  7. 7Say itLEVEL 2: INTERMEDIATE

    Add: Alert, then Say. Text: Today's word of the day is %WOTD. Save the action, then save the task.

  8. 8Test itLEVEL 1: BASIC

    With the phone connected to the internet and unlocked, tap the tag and wait a second or two for the request to finish before it speaks.

NOTE Step 6 depends on the exact wording of the page's title, which the site could change at any time. If the task stops saying anything, open the same page in a browser, check its title or view its page source for how the word is presented now, and adjust the search pattern to match. This is the same skill as the general troubleshooting steps above, just applied to a webpage instead of a tag.

Advanced: navigate home or to work automatically

Android and Tasker only, and a third tag: mount this one in the car, with no NFC Tools records written to it, same reasoning as the Intermediate example. One tag, two Tasker profiles that each combine the tag with a time window, so tapping it does something different depending on when you tap it: on a weekday morning it starts navigation to work, in the early evening it starts navigation home.

Set the two addresses once

  1. 1Create a Home address variableLEVEL 2: INTERMEDIATE

    In Tasker, open the Vars tab at the bottom, tap +, and enter %HomeAddress as the name. Tap the value field and type your home address, then save.

  2. 2Create a Work address variableLEVEL 2: INTERMEDIATE

    Repeat Step 1, naming it %WorkAddress and entering your work address instead.

Profile 1: weekday mornings, go to work

  1. 1Add the tag as the first contextLEVEL 2: INTERMEDIATE

    Profiles tab, tap +, then Event, then Plugin, then NFC for Tasker. Scan the car tag as in the Intermediate example.

  2. 2Add a time window as a second contextLEVEL 3: ADVANCED

    Back on the profile screen, tap + again to add a second context and choose Time. Set From to 07:00 and To to 09:30, then untick Saturday and Sunday so only weekdays apply. Tasker requires both contexts to be true together, so this profile now only fires from a weekday-morning tap.

  3. 3Attach a new task named "Drive to Work"LEVEL 2: INTERMEDIATE

    Enter the name and tap the checkmark.

  4. 4Start navigationLEVEL 3: ADVANCED

    Add: System, then Send Intent. Action: android.intent.action.VIEW. Data: google.navigation:q=%WorkAddress. Target: Activity. Save.

  5. 5Add a spoken confirmation (optional)LEVEL 1: BASIC

    Add: Alert, then Say, with text Good morning, navigating to work. Save the action, then save the task.

Profile 2: weekday evenings, go home

  1. 1Add the same tag as the first contextLEVEL 2: INTERMEDIATE

    Create a second, separate profile the same way: Profiles, +, Event, Plugin, NFC for Tasker, scanned to the same car tag.

  2. 2Add the evening time windowLEVEL 3: ADVANCED

    Add a Time context, From 16:00 To 19:00.

  3. 3Attach a new task named "Drive Home"LEVEL 2: INTERMEDIATE

    Enter the name and tap the checkmark.

  4. 4Start navigationLEVEL 3: ADVANCED

    Same as Profile 1's Step 4, but Data is google.navigation:q=%HomeAddress.

  5. 5Add a spoken confirmation (optional)LEVEL 1: BASIC

    Same as Profile 1's Step 5, with text Heading home, starting navigation.

NOTE Outside both windows, tapping the car tag does nothing, since neither profile's Time context matches. To give it a fallback, add a third profile on the same tag with no Time context and a lower priority (long-press the profile, then Priority, then a smaller number), whose task just opens a maps app with no destination set. Tasker checks profiles sharing a context in priority order, so the two time-specific ones are still tried first.
